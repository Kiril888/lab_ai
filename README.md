# Лабораторні роботи «Штучний інтелект для циркулярної економіки»

Кузьмак Кіріл, група КНм-26, варіант 9.

| Лаба | Тема | Головні файли |
|---|---|---|
| [ЛР1](lr1) | Формалізація задачі та аудит джерел даних (кейс: будівельна техніка й самоскиди) | `passport.yaml`, `lab1_data_review.ipynb` |
| [ЛР2](lr2) | Формування та контроль якості датасету (самоскиди, екскаватори, крани; рамки) | `lab2_dataset.ipynb`, `dataset_cdw_v1/`, `guideline_v2.md` |
| [ЛР3](lr3) | Класифікація фракцій відходів (ViT-B/16, фокальна функція втрат) | `lab3_classification.ipynb`, `extra_analysis.py` |
| [ЛР4](lr4) | Детектування провалів дахів і завалів (RetinaNet, зменшення роздільної здатності ×2) | `lab4_detection.ipynb`, `lab4_best_model_analysis.py` |

**Дані.** Усі набори синтетичні й генеруються скриптами з теки [`common/`](common)
(`synth_site.py`, `synth_textures.py`, `synth_damage.py`) з фіксованими зернами — повторний запуск
ноутбуків відтворює ті самі дані й розбиття. Для реальних даних (OpenAerialMap, xBD) досить покласти
їх у теки, вказані на початку відповідного ноутбука.

**Середовище:** Python 3.10+, залежності — `requirements.txt`. Ваги моделей у репозиторій не входять
(розмір > 100 МБ): ViT-B/16 і ResNet-50 (ImageNet) завантажуються через `timm`, якщо локального файлу немає.
