# Картка набору даних `dataset_cdw_v1`
(файл `dataset_cdw_v1/README.md`)

## Мотивація
Набір створено для детектування та підрахунку будівельної техніки на майданчиках знесення і відбудови
(паспорт експерименту ЛР1): оцінка інтенсивності робіт і потоку вивезення відходів.
Автор: Кузьмак Кіріл, КНм-26. Дата: 2026-11-06.

## Склад
- Плиток: 96; сцен: 6; ділянок: 5. Об'єктів: 115 (dump_truck 36, excavator 38, crane 11, other_vehicle 30).
- Класи: dump_truck, excavator, crane, other_vehicle. Об'єктів за класами: див. `stats/classes.csv`.
- Джерело: синтетичні ортофотоплани будмайданчиків (`synth_site.py`), GSD 0,05 м, EPSG:32635.
- Канали: RGB, 8 біт. Формат: PNG 640×640. Розмітка: YOLO 1.1 (`labels/*.txt`).
- Статистика розмірів об'єктів: `stats/stats.png`.

## Процес збирання
Сцени згенеровано скриптом `synth_site.py` (seed 101–106); site1 знято у дві дати.
Нарізання на плитки 640×640 з перекриттям 64 пкс; плитки з > 50 % nodata відкинуто.

## Анотування
Інструкція `guideline_v1.md` → `guideline_v2.md`; рамки — еталон генератора.
Узгодженість змодельовано двома «анотаторами» з шумом (30 плиток): F1@0,5 = 0,964, mean IoU = 0,790, kappa = 0,815;
після уточнення інструкції (10 плиток): F1 = 0,981, mean IoU = 0,885, kappa = 0,819.

## Розбиття
Групове за ділянками (`site`), seed = 5; 48/16/32 плитки; файл `split.csv`.
Витік: частка val/test з тією ж ділянкою у train = 0,00 (випадкове розбиття: 1,00);
дублікатів між підмножинами (dHash ≤ 6): 0.

## Обмеження та упередження
- Дані синтетичні: спрощені форми техніки, без артефактів ортофото.
- Мало ділянок (5) → тестова оцінка має широкий довірчий інтервал.
- Дисбаланс: crane рідкісний (11 об'єктів).

- Узгодженість змодельована, а не виміряна на людській розмітці.
